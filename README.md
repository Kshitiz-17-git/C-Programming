## 👋 About this repository

This repository is my collection of C programs as I learn the language. It brings together short concept examples, practice problems, and small projects—from the first `printf` to pointers, dynamic memory, and files.

Each topic is organized the same way:

| File or folder | What you'll find |
|---|---|
| `README.md` | A short explanation of the topic |
| `examples/` | Small programs demonstrating the concepts |
| `practice/` | Problems I solve to apply what I learned |

> **The idea:** learn a concept, see it in code, then practice it yourself.

## ▶️ Compile and run

You’ll need a C compiler such as GCC or Clang. From the repository root, compile a source file and run the program:

```bash
gcc 01-Getting-Started/examples/hello_world.c -o hello_world
./hello_world
```

On Windows with MinGW, run the generated program with:

```bash
gcc 01-Getting-Started/examples/hello_world.c -o hello_world.exe
hello_world.exe
```
